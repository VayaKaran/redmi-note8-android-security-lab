# Security Policy

## Scope

This repository documents an educational Android system-modification and Linux-learning project performed on the author's own Redmi Note 8.

It is not a security product and does not provide security guarantees for the device, ROM, applications, or external systems.

## Reporting

If you find a security issue in the documentation itself, open a GitHub issue only if the issue can be discussed publicly without exposing sensitive information.

Do not post:

- IMEI numbers
- serial numbers
- private IP addresses
- MAC addresses
- account credentials
- authentication tokens
- personal contact information
- private screenshots containing sensitive data

For vulnerabilities in third-party software such as LineageOS, Android, OrangeFox, or other projects, report them through the respective project's official security process rather than treating this repository as the vendor's security channel.
