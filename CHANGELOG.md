## Historical project milestones

### April 2026 — Project started
- Project began with Android OS/system learning goals.
- Device baseline was Redmi Note 8 running MIUI 12.5.

### 2026 — Bootloader and recovery work
- Xiaomi bootloader unlock process completed.
- ADB and Fastboot used.
- OrangeFox R10.0 used as an early custom recovery.

### 2026 — Pixel 3.6 experiment
- Pixel 3.6 installation attempted.
- Device entered a bootloop.
- Approximately four days were spent troubleshooting before successful boot.

### 2026 — Pixel testing
- Major phone functions were tested.
- Severe battery drain was observed.
- Battery degradation was suspected because of device age/history, but the exact cause was not experimentally established.

### 2026 — Termux/Linux learning
- Basic Linux/Ubuntu-style commands were started through Termux.
- First attempt was unsuccessful; a later attempt was successful.

### 2026 — Recovery loop
- Device later repeatedly booted into recovery instead of normal Android.
- Fastboot was used.
- OrangeFox R12.0 was installed.
- The device was subsequently moved to LineageOS 23.2 / Android 16.

### August 2026 — Current state
- Current LineageOS 23.2 / Android 16 build documented.
- Major hardware/system functions tested.
- ADB and Fastboot verified working.
- Termux/Linux command learning continued.
