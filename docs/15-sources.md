## Source categories

### Official/project sources

Use official project documentation for:

- bootloader information
- recovery documentation
- ROM installation requirements
- supported-device information
- security information

### Community sources

Community resources may help with historical device-specific troubleshooting, but should be clearly identified as community material.

### Search engines

Google Search was used for discovery. Search results themselves should not be treated as authoritative when an official source is available.

## Citation rule

For every technical procedure added in future:

- cite the original source,
- record the access date,
- identify whether it is official or community material,
- and distinguish the author's own actions from copied instructions.
