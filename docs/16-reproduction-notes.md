# 16 — Reproduction Notes

## Warning

This repository is primarily a documentation and learning project. It is **not** a guarantee that the historical flashing process can be reproduced safely on another device.

Android flashing can cause:

- data loss
- boot failure
- soft brick
- hard brick
- loss of functionality
- security degradation

## Historical reproducibility

The historical project cannot be reproduced exactly from the current record because exact ROM filenames, firmware versions, hashes, and some command sequences were not retained.

## Future reproducibility standard

For any new experiment, record:

```text
Device
Codename
Starting OS
Recovery
Firmware
ROM
File names
File hashes
Commands
Wipe/format actions
Result
Recovery method
```

Do not follow old instructions blindly. Verify current device-specific documentation before flashing.
