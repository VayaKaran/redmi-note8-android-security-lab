# 04 — Bootloader, ADB and Fastboot

## Workstation

- HP Notebook
- Windows 8.1
- 4 GB RAM
- Intel Core i3-U series processor

## Tools used

- Xiaomi Mi Unlock Tool
- ADB
- Fastboot
- Command Prompt
- OrangeFox Recovery

## Bootloader process — recorded account

1. Logged into the Xiaomi/Mi Unlock website.
2. Downloaded the bootloader-unlocking tool.
3. Selected the device/version as required by the tool.
4. Started the unlock process.
5. The phone became unlocked and was factory-reset.
