# 10 — Kali NetHunter Investigation

## Original objective

A major original goal of the project was to install Kali NetHunter on the Redmi Note 8.

## Investigation

The author researched device/kernel compatibility and concluded that the required NetHunter support was not available for the device.

The original project report also records that the required kernel/device support limited NetHunter deployment.

## Result

Kali NetHunter was **not successfully deployed** as part of this project.

## Why this matters

A failed compatibility investigation is still a useful engineering result.

The project demonstrates:

```text
Goal
  ↓
Compatibility research
  ↓
Support limitation discovered
  ↓
Original plan rejected
  ↓
Alternative learning path selected
```

## Current alternative

The phone is being used for:

- Android system learning
- Linux/Termux learning
- ADB/Fastboot practice
- Future mobile-security research

## Scope warning

This project does not claim to have successfully turned the Redmi Note 8 into a Kali NetHunter device.
