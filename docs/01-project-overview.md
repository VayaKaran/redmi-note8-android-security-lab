# 01 — Project Overview

## Project title

**Redmi Note 8 Android System Modification & Mobile Security Learning Lab**

## Author

**Karan Bhaveshbhai Vaya**

## Purpose

The project was started to learn how Android operating systems work, how custom ROMs are installed and recovered, and how Linux and cybersecurity concepts connect to mobile systems.

An initial goal was to install Kali NetHunter. Research later indicated that the required support was not available for this device/kernel combination, so the project evolved into Android system modification, Linux learning, troubleshooting, and preparation for future mobile-security work.

## Scope

The project covers:

- MIUI baseline
- Bootloader unlocking
- ADB/Fastboot
- Custom recovery
- Pixel 3.6 experiment
- Bootloop troubleshooting
- Battery-drain observation
- Recovery-loop troubleshooting
- LineageOS 23.2 / Android 16
- Functional testing
- Termux/Linux learning

It does not claim to be a completed Android penetration-testing laboratory.

## Outcome

The phone currently operates on LineageOS 23.2 / Android 16 and has been functionally tested across the major components listed in the project record.
